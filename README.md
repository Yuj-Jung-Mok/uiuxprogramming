### 새로 추가한 기능
- 7주차 설정 완료 화면에 '내 장르 만화 보러 가기'를 추가했다. 2단계에서 고른 즐겨찾기 장르의 만화만 모아 보고, 작품 이름으로 검색하고, 마음에 드는 작품을 즐겨찾기에 담거나 뺄 수 있다.
- 7주차 흐름의 끝(설정 완료)에 연결했다. 7주차에서는 장르를 고르기만 했는데, 이제 고른 장르가 실제 만화 목록에 반영된다.

### 사용자 흐름
1. 7주차 흐름을 마치고 완료 화면에서 '내 장르 만화 보러 가기'를 누른다.
2. 선택한 장르의 만화 목록을 확인하고, 필요하면 작품 이름을 검색한다.
3. 마음에 드는 작품의 '즐겨찾기 담기'를 누른다. 뺄 때는 확인 창에서 결정한다.
4. '설정 완료 화면으로'를 눌러 돌아가면 담은 작품 수가 완료 문구에 반영된다.

### 사용자 행동과 조건
1. 모아보기 열기
- 행동, 이벤트: 완료 화면에서 '내 장르 만화 보러 가기'를 클릭한다.
- 조건: 7주차 2단계에서 책갈피 기능과 함께 장르를 골랐는가?
- 성공 반응: '선택한 장르(액션 · 판타지)의 만화를 보여 줍니다.' 안내와 함께 고른 장르의 작품만 보이고, '내 장르 작품 4개'처럼 개수가 표시된다.
- 다른 분기: 고른 장르가 없으면 '선택한 즐겨찾기 장르가 없어 전체 장르의 만화를 보여 줍니다.'를 강조해 안내하고 전체 작품을 보여 준다.
- 다음 행동: '장르 고르러 가기'를 누르면 입력값을 유지한 채 2단계(읽기 조건)로 돌아간다.
2. 작품 검색
- 행동, 이벤트: '작품 이름 검색'에 검색어를 입력하고 '검색하기'를 누르거나 Enter를 누른다.
- 조건: 지금 보는 장르 범위 안에 검색어가 들어간 작품이 있는가?
- 성공 반응: 맞는 작품만 남기고 "'마법' 검색 결과 1개 작품"을 표시한다. 검색어 없이 검색하면 내 장르 작품을 모두 보여 주고 '검색어가 비어 있어 작품 4개를 모두 보여 줍니다. 찾을 작품 이름을 입력해 주세요.'라고 안내한다.
- 결과 없음: "내 장르에는 '빵집'에 맞는 만화가 없습니다. 검색어를 지우거나 전체 장르에서 찾아 보세요."를 표시한다.
- 다음 행동: '전체 장르에서 찾기'는 같은 검색어로 전체 장르를 찾는다. 전체 장르에서도 없으면 '검색어 지우기'만 남는다. '검색어 지우기'를 누르거나 새로 검색하면 다시 내 장르에서 보여 준다.
3. 즐겨찾기 담기
- 행동, 이벤트: 작품 카드의 '즐겨찾기 담기'를 클릭한다.
- 조건: 이미 3개를 담았는가?
- 성공 반응: 카드 테두리가 강조되고 버튼이 '즐겨찾기 빼기'로 바뀐다. '내 즐겨찾기 1 / 3개'와 담은 작품 이름이 갱신되고, "'불꽃 검객'을(를) 즐겨찾기에 담았습니다."가 표시된다.
- 오류: 3개를 넘기면 '즐겨찾기는 최대 3개까지 담을 수 있습니다. 다른 작품을 빼고 다시 담아 주세요.'를 표시하고 담지 않는다.
- 다음 행동: 다른 작품을 뺀 뒤 다시 담을 수 있다.
4. 즐겨찾기 빼기
- 행동, 이벤트: '즐겨찾기 빼기'를 누르면 확인 창이 열린다. 확인 창에서 '빼기', '그대로 두기' 또는 Esc를 누른다.
- 조건: 정말 뺄 것인가, 취소할 것인가?
- 성공 반응: '빼기'를 누르면 목록에서 사라지고 개수가 줄며, 버튼이 '즐겨찾기 담기'로 돌아온다.
- 취소: '그대로 두기'나 Esc를 누르면 창만 닫히고 즐겨찾기는 유지된다. "'불꽃 검객'을(를) 즐겨찾기에 그대로 두었습니다."를 표시한다.
5. 돌아가기와 다시 설정
- 행동, 이벤트: '설정 완료 화면으로' 또는 완료 화면의 '다시 설정하기'를 클릭한다.
- 조건: 이전 화면으로 돌아가는가, 처음부터 다시 하는가?
- 반응: '설정 완료 화면으로'는 '즐겨찾기에 3개 작품을 담았습니다.'를 완료 문구에 반영하고, 다시 들어오면 담은 작품과 검색어가 유지된다. '다시 설정하기'는 7주차 입력값과 함께 즐겨찾기, 검색어, 장르 범위, 안내 문구를 모두 초기화한다.

### 구현 내용
- HTML: 완료 화면에 다음 행동 버튼, 새 단계, 검색 폼, 작품 카드 6개, 즐겨찾기 영역, 빼기 확인 dialog를 추가했다.
- CSS: 카드 Grid, 즐겨찾기 상태(.is-favorite), 결과 없음, 성공(.is-success), 경고, 안내 상태와 다크 테마를 추가했다. 768px 이하에서는 버튼과 입력창을 한 열로 배치한다.
- JavaScript: showStep으로 단계를 전환한다. 검색은 submit과 preventDefault로 처리한다. querySelectorAll과 forEach로 카드의 hidden을 바꾸고, data-target으로 카드를 찾아 classList와 textContent를 갱신한다. 빼기는 showModal과 close로 확인한다.

### 테스트 결과
- 정상 경로: 액션과 판타지 선택 → 완료 → 모아보기에서 4개 작품 표시 → '마법' 검색 1개 → 즐겨찾기 담기 → 완료 화면에 담은 개수 반영 (확인)
- 결과 없음: 내 장르에서 '빵집' 검색 시 결과 없음 안내 → '전체 장르에서 찾기'로 1개 표시 → '검색어 지우기'로 내 장르 4개로 돌아옴 (확인)
- 장르 없음: 장르 없이 완료 → 전체 장르 안내와 '장르 고르러 가기' 표시 → 2단계로 돌아가 제목 값 유지 확인 → 일상 선택 후 일상 2개만 표시 (확인)
- 빈 검색어: 검색어 없이 '검색하기'를 누르면 내 장르 4개를 보여 주고 검색어 입력 안내 표시, 검색창에 커서 이동 (확인)
- 오류: 내 장르 작품 3개를 담은 뒤 4번째 담기 시 최대 개수 안내, 개수는 3 / 3개 유지 (확인)
- 취소: 빼기 확인 창에서 '그대로 두기'와 Esc 모두 즐겨찾기 유지 (확인)
- 수정: 빼기 확정 후 2 / 3개로 줄고, 다른 작품을 다시 담을 수 있음 (확인)
- 돌아가기와 초기화: 완료 화면으로 갔다가 다시 들어와도 즐겨찾기 유지, '다시 설정하기' 후 0 / 3개로 초기화 (확인)
- 화면: 1100px와 390px에서 가로 스크롤 없이 카드, 버튼, 입력창이 겹치지 않음, 다크 테마에서도 글자 확인 가능 (확인)

## 6주차 이벤트 처리와 동적 UI 구현

### 구현한 이벤트
- click: 화면 테마 버튼으로 다크 테마 전환
- click: 탭 3개로 기능 전환
- input: 만화 이름 글자 수 표시, 이메일 수정 시 신청 상태 초기화
- change: 동의 체크박스로 "만화 보기" 버튼 활성화

### 화면 변화

- 탭 클릭 시 선택 탭 표시와 해당 패널만 표시
- 다크 테마 전환 시 배경, 글자, 카드 색 변경
- 신청 완료 시 버튼 비활성화, 이메일 수정 시 다시 활성화

### 테스트 결과

## 7주차 사용자 흐름과 인터랙션 시나리오 구현

# 만화 보여주는 서비스

## 사용자 목표
- 사용자 : 만화를 보고싶은 사람
- 목표 : 만화를 즐겁게 보기

## 핵심 행동
- 만화 정보 활용에 동의하고, 만화 제목과 읽기 조건을 설정해 만화 보기를 시작한다.

## 완료 조건
- 동의 체크 후 안내 창에서 '동의하고 만화 보기'를 누른다.
- 만화 제목을 입력하고 '내용 확인하기'를 누른 뒤 확인 화면에서 '설정 완료하기'를 누른다.
- 완료 화면에 "만화 보기 설정이 완료되었습니다."가 표시되면 완료로 본다.

## 사용자의 흐름
1. 만화 정보 활용에 동의하고 '만화 보기'를 누른다.
2. 안내 창에서 '동의하고 만화 보기'를 누르면 만화 제목 입력 화면이 열린다. 돌아가기나 Esc를 누르면 동의가 해제되고 시작 화면에 남는다.
3. 만화 제목, 보여줄 회차 수, 책갈피 기능을 설정하고 '내용 확인하기'를 누른다.
4. 입력한 내용을 확인하고 '설정 완료하기'를 누르거나, '수정하기'로 돌아가 고친다.
5. 설정 완료 안내를 확인하고, 필요하면 '다시 설정하기'를 누른다.

## 인터랙션 시나리오
1. 시작과 동의 확인
- 행동, 이벤트: 동의 체크박스를 선택하고 '만화 보기'를 클릭한다.
- 조건: 동의 체크박스가 선택되었는가?
- 반응, 다음 상태: 동의 전에는 '만화 보기' 버튼이 비활성화되어 클릭할 수 없다. 동의하면 버튼이 활성화되고 안내 문구가 바뀐다. 동의 후 클릭하면 안내 창이 열린다.
2. 안내 확인
- 행동, 이벤트: 안내 창에서 '동의하고 만화 보기'를 클릭하거나, '돌아가기' 또는 Esc를 누른다.
- 조건: 동의를 확인했는가, 아니면 취소했는가?
- 반응, 다음 상태: 확인하면 창을 닫고 설정 흐름을 보여준 뒤 1단계(만화 제목 입력)를 열고 입력창에 초점을 둔다. 취소하면 창을 닫고 동의를 해제해 시작 화면에 남는다.
3. 만화 제목과 조건 입력
- 행동, 이벤트: 만화 제목을 입력하고 '읽기 조건 선택하기'를 클릭한다. 회차 수를 조절하고 책갈피 기능을 선택한 뒤 '내용 확인하기'를 클릭한다.
- 조건: 앞뒤 공백을 제외한 제목이 비어 있는가?
- 반응, 다음 상태: 비어 있으면 '만화 제목을 입력해 주세요.' 안내를 표시하고 입력창을 빨간 테두리로 강조한다. 값이 있으면 2단계로 넘어간다. 책갈피를 선택하면 장르 묶음이 나타나고, 내용 확인 후 3단계로 넘어간다. '이전'을 누르면 입력한 값이 그대로 남는다.
4. 내용 확인과 수정
- 행동, 이벤트: 확인 화면에서 '수정하기' 또는 '설정 완료하기'를 클릭한다.
- 조건: 수정할 내용이 있는가?
- 반응, 다음 상태: '수정하기'를 누르면 2단계로 돌아가고 입력값이 유지된다. 확인 화면에는 만화 제목, 보여줄 회차 수, 책갈피 사용 여부, 선택한 장르 개수가 줄을 나눠 나온다. 수정 후 다시 확인하면 바뀐 값이 확인 화면에 반영된다. '설정 완료하기'를 누르면 4단계 완료 화면으로 넘어간다.
5. 완료와 다시 설정
- 행동, 이벤트: 완료 안내를 확인하고 '다시 설정하기'를 클릭한다.
- 조건: 설정을 처음부터 다시 하려는가?
- 반응, 다음 상태: 제목, 회차 수, 책갈피, 장르 선택, 오류 표시, 확인 목록을 모두 초기화하고 1단계 제목 입력부터 다시 시작한다. 동의 상태는 유지된다.

- 모바일 화면: 화면이 잘리지 않고 보임 (확인)
