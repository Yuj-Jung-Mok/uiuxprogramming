## 4주차 반응형 수정

### 확인할 문제
작은 화면에서 메뉴, 기능 카드, 이메일 폼이 좁여 보였다.

### 수정한 내용
- viewpoer 메타 태그를 추가했다.
- 콘텐츠에 width와 max-width를 함께 사용했다.
- 기능 카드 목록을 반응형 Grid로 변경했다.
- 768px 이하에서 메뉴, 카드, 폼을 한 열로 구성했다.

### 확인할 화면 너비
1100px / 769px / 768px / 390px

## 6주차 이벤트 처리와 동적 UI 구현

### 구현한 이벤트
- click: 화면 테마 버튼으로 다크 테마 전환
- click: 탭 3개로 기능 전환
- input: 만화 이름 글자 수 표시, 이메일 수정 시 신청 상태 초기화
- change: 동의 체크박스로 "만화 보기" 버튼 활성화

### 화면 변화
- 동의 체크 시 버튼 활성화, 안내 문구와 스타일 변경
- 탭 클릭 시 선택 탭 표시와 해당 패널만 표시
- 다크 테마 전환 시 배경, 글자, 카드 색 변경
- 신청 완료 시 버튼 비활성화, 이메일 수정 시 다시 활성화

### 테스트 결과
- 1100px: 화면 잘림 없이 기능 작동 (확인)
- 768px: 동의 체크박스 문구가 옆에 나란히 배치됨 (확인)
- 390px: 화면 잘림 없이 탭 세로 배치 및 기능 작동 (확인)
- 탭 클릭 시 패널 전환 (확인)
